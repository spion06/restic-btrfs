# rbtrfs completions

Print a shell completion script

## Usage

```
rbtrfs completions [OPTIONS] <SHELL>
```

## Arguments

### `<SHELL>`

Shell to generate for: bash, zsh, fish, elvish or powershell.

## Options

### `-c, --config <CONFIG>`

Config file. Defaults to $RBTRFS_CONFIG, then /etc/rbtrfs/config.toml.
